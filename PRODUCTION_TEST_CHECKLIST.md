# Production Test Checklist

Execute these 16 mandatory tests post-deployment to verify complete transaction safety, idempotency, and concurrency correctness.

- [ ] **TEST 1: Single Save**
  - Press Save once on a new sales invoice. Verify exactly one transaction and invoice are created.
- [ ] **TEST 2: Rapid F2 Keypresses**
  - Press F2 (or click Save) twice rapidly. Verify frontend save lock prevents duplicate submission and exactly one transaction is created.
- [ ] **TEST 3: Double-Click Protection**
  - Double-click the Save button. Verify exactly one transaction is created.
- [ ] **TEST 4: Idempotency Retry**
  - Retry the exact same `request_id`. Verify the database returns the existing transaction without duplication.
- [ ] **TEST 5: Timeout Recovery**
  - Simulate a network response timeout after DB commit, then retry. Verify no duplicate invoice is generated.
- [ ] **TEST 6: Concurrent Sales**
  - Create two sales simultaneously from two browser sessions. Verify inventory stock quantities remain perfectly accurate without lost updates.
- [ ] **TEST 7: Edit Sales Invoice**
  - Edit an existing sales invoice (changing items/quantities). Verify original stock effect is reversed and new effect applied exactly once.
- [ ] **TEST 8: Edit Purchase**
  - Edit an existing purchase invoice. Verify stock increase and supplier balance adjustments are correctly reversed and re-applied.
- [ ] **TEST 9: Sales Return**
  - Process a Sales Return. Verify return record, stock restoration, and customer balance adjustment occur atomically in a single transaction.
- [ ] **TEST 10: Purchase Return**
  - Process a Purchase Return. Verify return record, stock reduction, and supplier balance adjustment occur atomically.
- [ ] **TEST 11: Database Error Handling**
  - Simulate a database rejection (e.g., database offline or constraint violation). Verify the UI does **not** display success.
- [ ] **TEST 12: Multi-Company Isolation**
  - Record a payment in Company A. Verify it never allocates or affects invoices in Company B.
- [ ] **TEST 13: Unique Document Numbers**
  - Create simultaneous invoices. Verify document numbers generated by atomic database counters are strictly unique.
- [ ] **TEST 14: Historical Record Preservation**
  - Verify all existing historical production records remain intact and readable after applying the migration.
- [ ] **TEST 15: Post-Save Browser Refresh**
  - Refresh the browser immediately after a successful save. Verify no duplicate transactions appear.
- [ ] **TEST 16: Session Persistence & Logout**
  - Perform logout and login cycles. Verify user session state and data consistency remain intact.
